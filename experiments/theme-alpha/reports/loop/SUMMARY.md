## 4. 逐假设：主题信号在哪里失效

- **H1（萌芽 · 注意力领先）：三个案例均不支持。**
  - 维基浏览量（美、港）没有产生跃迁；成交额异常的跃迁滞后。
  - 唯一领先的信号是港股的 GitHub 星标，但它领先到上市之前，当前回放计不了分。
  - 建议：在系统检验中保留 H1，但把"注意力处于高位且仍在上升"改作 H4 的拥挤输入，并在冻结前预注册这一改动。
- **H2（扩散 · 时间序列动量）：主题篮子层面有效。**
  - 4 周动量捕获的超额占买入持有的比例：美股 82%，光通信 75%，港股 27%。
  - 港股的低捕获来自两只股票极端分化，篮子动量在 3 月后被 MiniMax 的回撤稀释。这支持 LOOP §5 的判断：主题层面的动量不够。
- **H3（低可见度溢出）：光通信的第二梯队不滞后。**
  - 第二梯队为 66 只主题 ETF 前十大持仓。最佳滞后为 0 周，下周回归 t = -2.0。A 股题材扩散快，与 SPEC 中"若失败"的解释一致。
  - 美股和港股没有 PIT 持仓源，无法评估。
- **H4（拥挤 · ETF × 隐含预期）：机制能工作，但对主题类型敏感。**
  - 太空（叙事型、亏损、ETF 扎堆）：提前 12 周标记，回撤 56% 前离场，代价是错过最后一段约 23 个百分点的累计超额。
  - 光通信（业绩兑现型）：即便有收入放缓确认，仍是误报，退出价值 -1.77。
  - 港股：根本没有可用的 ETF 信号。

## 5. 同主题内的分化（智谱 vs MiniMax）

| 时点 | 隐含 10 年收入 CAGR：智谱 / MiniMax | 此后 13 周收益：智谱 / MiniMax |
|---|---|---|
| 2026-02-27 | 101% / 100% | +177% / +10% |
| 2026-03-13 | 99% / 105% | +107% / -61% |
| 2026-05-15 | 103% / 97% | +22% / -59% |
| 2026-06-19 | 118% / 88% | -63% / -39% |

两家公司的隐含预期几乎一样，都隐含 10 年约 100% 的年均收入增速，排序也与随后收益不一致。

**结论：**主题信号和反向 DCF 都只能说明"两家都被定价成极端成功"。真正事前可知的区分变量是供给：首批解禁比例分别为 5.76% 和 44.85%，日期在招股书中已公告。不继续用旋钮去"修"这个分化，这正是 LOOP.md §5 要求写下的结论。
